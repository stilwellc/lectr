# Engine accuracy report: September 2026

Window: lots that settled **2026-09-01 → 2026-09-30**. Generated 2026-10-06 01:48 UTC by `scripts/accuracy-report.ts`.

**Basis.** HAMMER. lectr = served expectedHammerUsd (else served all-in value ÷ the lot premium factor); house = estimate midpoint (hammer); realized = the published hammer, else realized all-in ÷ the lot premium factor. Errors are log errors: med abs err = exp(median|ln(actual/pred)|)−1; ±30% = |ln(actual/pred)| ≤ ln 1.3; bias = exp(median ln(actual/pred)), >1 means lots sold ABOVE the call.

Sample rules: a figure needs n ≥ 10 to print (else "—"); under n 30 it is marked *thin* and should not be read as a trend.
